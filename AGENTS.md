# Инструкции для Node

- Это серверная часть WBSHOP на Node.js/Express с PostgreSQL.
- Сохранять разделение маршрутов, middleware, сервисов, утилит и инфраструктуры.
- Для каждого защищённого маршрута проверять JWT и принадлежность данных пользователю из `req.user`, а не только значения из запроса.
- Не добавлять SQL через конкатенацию пользовательского ввода; использовать параметризованные запросы и белые списки идентификаторов.
- Не возвращать API-ключи и секреты клиенту; шифрование и расшифровка остаются на сервере.
- Изменения схемы оформлять новой миграцией; не редактировать применённые миграции без отдельного решения.
- Для финансовых расчётов проверять идемпотентность, период, знаки сумм, округление и повторный запуск.
- После изменений запускать доступную синтаксическую/интеграционную проверку; реальные БД и ключи маркетплейсов явно отмечать как внешние зависимости.
- Не анализировать `node_modules`, логи, `.env`, дампы, резервные копии и сгенерированные артефакты.
