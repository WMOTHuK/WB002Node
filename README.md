# Node — бэкенд WBSHOP

Node.js-бэкенд на Express (ES modules) с PostgreSQL через `pg`. Сервер находится в `src/server.js`, приложение и маршруты подключаются в `src/app.js`.

## Слои

- `src/api/` — маршруты, middleware и контроллеры;
- `src/services/` — бизнес-логика пользователей, товаров, финансов, CRM, ключей и планировщиков;
- `src/utils/` — SQL-утилиты, шифрование, даты, логирование и интеграционные помощники;
- `src/config/` — настройки БД и URL API маркетплейсов;
- `src/infrastructure/` — планировщик и DB listener;
- `migrations/` — последовательные SQL-изменения схемы;
- `scripts/` — создание и проверка миграций.

## Команды

```powershell
npm install
npm run dev
npm start
npm run migrate
npm run migrate:create
npm run migrate:status
```

При запуске выполняются миграции и восстанавливаются задачи планировщика. Нужны переменные окружения для PostgreSQL, JWT, шифрования ключей и интеграций.

## Наблюдения после первичного анализа

- `server.js` запускает миграции перед HTTP-сервером и инициализирует in-memory планировщик.
- В нескольких маршрутах нужна отдельная проверка авторизации и принадлежности данных пользователю.
- В `services/db/db.service.js` список `allowedTableNames` пуст, хотя аналогичный список объявлен в конфигурации БД.
- В `auth.service.js` проверка уникальности логина выглядит несогласованной с формой результата `db.select`; это нужно подтвердить тестом.
- При graceful shutdown вызывается `closeDbListener`, но в просмотренном `server.js` его импорт/определение не обнаружено.
